**Измерение**

Счётчик Метрики: 110370022. На статических страницах добавлено отслеживание buy_intent и subscribe_intent. На основном сайте сохранены artwork_open, outbound_click и другие события. Начальный визит больше не отправляет дополнительный hit сразу после init.

В кабинете нужно проверить наличие целей с идентификаторами buy_intent и subscribe_intent. Код отправки события сам по себе не означает, что цель уже создана в интерфейсе Метрики. Клик по кнопке не равен сообщению или продаже.

Еженедельно фиксировать: даты, посещения из поиска, посещения с Pinterest, посещения из Telegram, переходы по покупке, переходы в канал, реальные обращения, продажи, примечания. Исходная статистика недоступна: присланная ссылка Метрики перенаправляет на вход в Яндекс.
